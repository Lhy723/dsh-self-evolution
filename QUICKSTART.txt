dsh-self-evolution 0.1.0
A benchmark-driven self-evolution bundle for DeepSeek Harness.

Install (any one):

  # published to npm
  dsh plugin --profile <name> add dsh-self-evolution

  # straight from GitHub
  dsh plugin --profile <name> add github:Lhy723/dsh-self-evolution

  # local tarball
  dsh plugin --profile <name> add ./dsh-self-evolution-0.1.0.tgz

Verify:

  dsh --profile <name> --dump-config
  # ...should print the `self-evolution` row under "# == dsh-self-evolution".

Requirements:

  - `dsh` and `pnpm` on PATH (the `dsh plugin` command forwards to pnpm);
  - the profile provides tools, subagents, and the spawn provider
    (@deepseek-ai/dsh-base does).

Next:

  Read README.md for Profile and Benchmark formats, the tool reference, and
  the configuration table. examples/config/self-evolution.row.yml shows the
  alternative isolated agent-preset mount.

Validation shipped with this release: strict TypeScript build against the
published 0.1.0-rc.6 declarations, 9/9 Node tests, a real dsh-tools /
dsh-invariants registration smoke, and a real-launcher --dump-config
composition check. Live model runs require a profile with credentials; see
COMPATIBILITY.md for the acceptance steps.
